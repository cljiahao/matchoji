# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/cljiahao/matchoji/security/advisories/new)
rather than in a public issue or pull request. Include what you found, how to reproduce it, and
what an attacker could do with it.

You will get an acknowledgement within a week. Please give us a reasonable time to fix the
issue before disclosing it.

## Scope

The deployed site and this repository: the Next.js app, the Supabase schema and row-level
security in `supabase/migrations/`, and the CI workflows. Third-party services (Supabase,
Vercel, Google sign-in) have their own disclosure programmes.
