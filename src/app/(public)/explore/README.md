# explore

## Purpose

`/explore`: every tea, filtered by the URL (`?q=&category=&region=&sort=`). A filter rail of
links (tea, region), a search pill that keeps the other filters, a sort select, and wide
result rows. A search or region that matches nothing shows "No teas match" with a
clear-filters link; an empty catalogue invites the first tasting.
