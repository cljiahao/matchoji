# [slug]

## Purpose

One café: name, area, address, Instagram handle and website links, its taster and community scores, a map pin, its drinks, and the latest trusted-taster reviews. A merged café permanently redirects to the one that absorbed it; a rejected, unknown or malformed slug is `notFound()`. `generateMetadata` and the page share one read through `cache`. `[drink]/` holds the drink pages.
