# sell

## Purpose

`/sell`, "Sell on Matchoji": signed-out visitors are asked to sign in; a user with no shop
sees the application form; a pending or rejected shop sees its status and can edit its
details; an approved vendor manages listings (their teas, an add form offering only teas not
yet listed, defaulting to their last currency) and shop details. Rendered per request.
