# app

## Purpose

Next.js App Router tree — pages, layouts, and API route handlers.

## Contents

- `(public)/`
- `api/`
- `dashboard/`
- `error.tsx`
- `globals.css`
- `layout.tsx`

## Connectivity

`(public)/` and `dashboard/` are the two route groups; `api/` holds server route handlers. `layout.tsx`, `globals.css`, and `error.tsx` form the shared root shell (fonts, theme, providers, global error boundary) every route group renders inside.
