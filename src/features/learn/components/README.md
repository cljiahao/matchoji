# components

## Purpose

`CourseCard` (level, lesson count and length), `CourseLessonList` (the outline, ticking finished
lessons and counting them for a signed-in learner), `LessonCompleteButton` ("Mark lesson as done" /
"Lesson done"), `RecipeCard` (the Learn tab's tiles: category, title, summary and brew numbers),
`BrewFacts` / `brewFacts` (a recipe's tea, water, temperature, milk and time as a tile row)
and `LogRecipeButton` (the tasting dialog pre-filled with a recipe's prep; signed-out visitors
are asked to sign in, as with every log button).
