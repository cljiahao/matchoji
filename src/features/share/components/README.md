# components

## Purpose

The share-image layouts, drawn with inline styles and SVG because `next/og` renders no CSS classes. `SiteCard`, `TeaCard` and `ProfileCard` (`share-cards.tsx`) are the three 1200×630 cards; `ShareTin` is `TeaTin`'s drawing without the label art; `LogoMark` is `public/image_assets/logo.svg` redrawn.
