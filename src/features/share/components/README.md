# components

## Purpose

The share-image layouts, drawn with inline styles and SVG because `next/og` renders no CSS classes. `SiteCard`, `TeaCard`, `ProfileCard` and `YearCard` (`share-cards.tsx`) are the 1200×630 cards; `YearCard` takes `YearCardData`, which holds counts and tea names only; `ShareTin` is `TeaTin`'s drawing without the label art; `LogoMark` is `public/image_assets/logo.svg` redrawn.
