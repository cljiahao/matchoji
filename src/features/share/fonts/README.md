# fonts

## Purpose

Figtree Regular, Bold and ExtraBold as static TTF files, loaded from disk by `../lib/fonts.ts` so share images never fetch a font at request time (satori cannot read the woff2 that `next/font` serves). Licensed under the SIL Open Font License; the text is in `OFL.txt`.

## Contents

- `Figtree-Bold.ttf`
- `Figtree-ExtraBold.ttf`
- `Figtree-Regular.ttf`
- `OFL.txt`
