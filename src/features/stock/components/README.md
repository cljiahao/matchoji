# components

## Purpose

`StockPanel`: "Stock at the official shop" on the product page. Shows the latest fresh
report (an icon and a word, never colour alone) and its age, links to the maker's shop in a
new tab, and offers "In stock" / "Sold out" buttons. Its tests cover display, staleness,
reporting, the rate-limit message and the signed-out prompt.
