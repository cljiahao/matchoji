# components

## Purpose

`MatchSummary` (tea page): "86% match for you · Great match" and "Because you rated …", or an
invitation to rate a first tea. `MatchBadge` (Explore rows): "86% match", band in words for
screen readers. `YourTaste` (journal, and a taster's profile via its `title`): the taste profile, with a table of loved versus disliked
taste out of 5.
