# constants

## Purpose

Environment-derived and route-path constants shared across the app. `routes.ts` lists the page
routes (`/`, `/explore`, `/regions`, `/regions/supply`, `/journal`, `/sell`); dynamic product pages are built inline as `/products/<id>`.
