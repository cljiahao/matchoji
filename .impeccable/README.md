# .impeccable

## Purpose

Workflow config and surface briefs for the `impeccable` design skill — records this project's chosen build path (comp-first vs code-first) and per-surface direction contracts, so decisions aren't re-asked or re-decided every session.

## Contents

- `config.json`
- `design.json`
- `surfaces/`

## Connectivity

`surfaces/` holds one direction-contract brief per named surface (e.g. `phase1.md`), written before that surface is built and read back by later edits to that same surface. `design.json` is the machine-readable sidecar of `DESIGN.md` (tokens, and components such as the score numeral, flavour-note chips, taste-profile bars, rating distribution, journal stats and the want-to-try toggle), regenerated whenever the design system changes.
